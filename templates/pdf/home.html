PDF

Opens a PDF from this device in this browser only. The file is read in this tab and is not uploaded, stored or shared. It is gone when you close it or leave the page.

Limits

Files up to 50 MB open; that is a browser memory limit, not a storage rule. Password-protected files, some scanned-image formats (JBIG2, JPEG 2000) and some East Asian fonts are not supported yet. Find searches the extracted text of the open file only (no scans or images), so it can miss words and a "no match" does not prove the text is absent. Notes you add stay in this browser, matched to the exact file contents: they are not written into the PDF, an edited copy of the file is a different file with no notes, and another device will not have them. Signing out does not delete them, so on a shared computer delete them first. Notes are saved only over a secure (https) connection, because saving needs a browser feature that makes two open tabs safe. Download notes as text to keep them elsewhere, or download a copy of the file with your notes added as text annotations: it is built in this browser, is a new file, and leaves the file you opened as it was. Encrypted or damaged files cannot be copied this way, and some viewers show the note icon but not its text. No highlights drawn on the page, form filling, signing or printing yet. The page text below the picture can be selected and read by a screen reader.
