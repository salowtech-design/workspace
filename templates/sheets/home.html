Sheets

Kept in this browser only. Formulas start with =. Subset of spreadsheet features, no sharing.

Supported functions and limits

Functions: SUM, AVERAGE, MIN, MAX, COUNT, ABS, ROUND, LEN, UPPER, LOWER, CONCAT, IF, AND, OR, NOT. Operators + - * / ^ & % and comparisons. This is a subset, not full Excel or Google Sheets compatibility. The visible grid is A1 to H20. Errors: #DIV/0!, #VALUE!, #NAME?, #REF!, #CIRC!, #PARSE!, #LIMIT! (too deep or too much work).

Where this sheet is stored

Only in this browser, as a separate copy for each signed-in person, which keeps people apart inside the app. It is not sent to the server, not shared, not synced and not a backup. It is not encrypted against someone who can open this browser's storage. It stays on this device after you sign out until you clear it, and the browser can clear it. Use Export (.json) to keep a copy.

Tabs are stored in this browser only. Only the most recently deleted tab can be restored, and only until you reload. Keep one browser window on this sheet.

More about tabs

Up to 10 tabs. Each tab has its own cells, and formulas read only cells on their own tab. Undo, Export (.json), the CSV download, the chart, Sort, Filter and Import work on the tab you are on. Import replaces only that tab. Export (.json) and the CSV download save one tab at a time, so to back up a whole file export each tab. A change to the tab list made in another window stops this one until you reload, and an edit to a tab that another window deleted is not saved.

Arrow keys move, Enter moves down, Esc cancels an edit, Ctrl+Z and Ctrl+Y undo and redo.

Sort and filter

Sort moves whole rows of typed values and is saved like an edit (Undo works). It refuses a range that holds formulas. Formulas outside the range that refer to cells inside it keep their addresses, so their results can change after a sort. Going up, numbers come before text and blank cells go last; going down, text comes before numbers and blanks still go last. Text is compared as lowercase characters by code, not in any language's alphabet order (for example accented letters come after z). Sort moves hidden rows too. Filter only hides rows on screen and changes no data. It resets when you reload the page. Editing a cell can make its row disappear when the filter re-applies. Hidden rows are still included in Export, the CSV download, the chart and formulas (a SUM counts them). It uses the values shown, so formula results count.
