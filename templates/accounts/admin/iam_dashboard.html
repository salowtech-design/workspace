Primary Hasher
✓ Argon2id (RFC 9106)

Memory-hard modern password hashing with constant-time dummy verification on unknown identities to neutralize timing attacks.

Password Complexity
✓ 12-Character Minimum

Disallows common dictionary words and employee attributes (ID, name). Long passphrases permitted without artificial truncation.

Employee ID Syntax Normalization & Role Marker Validation (Section 6)

Accepted identifier formats: name-role-number (e.g. ST-EMP-0001) and name-role (e.g. ALICE-DEV).

🔒 Security Invariant: The role string inside an employee ID is never authorization. Effective privileges come exclusively from database role grants. Mismatches between identifier role marker and database role trigger rejection and audit without revealing account existence.
