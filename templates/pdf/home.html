PDF

Opens a PDF from this device in this browser only. The file is read in this tab and is not uploaded, stored or shared. It is gone when you close it or leave the page.

Limits

Files up to 50 MB open; that is a browser memory limit, not a storage rule. Zoom 100% is the page width (at most 1600 px). Fit page scrolls the page area to the top of the window and shows the whole page in the window height less a small margin, and its percentage is relative to that 100%; resizing the window refits. Password-protected files, some scanned-image formats (JBIG2, JPEG 2000) and some East Asian fonts are not supported yet. Find searches the extracted text of the open file only (no scans or images), so it can miss words and a "no match" does not prove the text is absent. Notes you add stay in this browser, matched to the exact file contents: they are not written into the PDF, an edited copy of the file is a different file with no notes, and another device will not have them. Signing out does not delete them, so on a shared computer delete them first. Notes are saved only over a secure (https) connection, because saving needs a browser feature that makes two open tabs safe. Download notes as text to keep them elsewhere, or download a copy of the file with your notes added as text annotations: it is built in this browser, is a new file, and leaves the file you opened as it was. Encrypted or damaged files cannot be copied this way, and some viewers show the note icon but not its text. No highlights drawn on the page, form filling, signing or printing yet. The page text below the picture can be selected and read by a screen reader.

A copy with notes is a new file built in this browser. It rewrites the whole file, so a digital signature in the original will not validate in the copy. Copies are limited to 20 MB and the page may pause while one is built.

        Builds a new PDF in this browser from the pages you choose, or from this file followed by the files you add (up to 10 files, 1000 pages, 20 MB of input). The files you opened are not changed and nothing is stored. Only pages are copied: the fillable form definition, bookmarks, document settings, links to other pages and most actions (document scripts are not copied) are left out; web links are kept. A form field keeps the look it had on the page, and how another viewer treats it is not checked. A digital signature in an input does not validate in the new file.

        Fills the standard form fields (text, check boxes, choices) in this browser and downloads a separate copy. The file you opened is not changed and what you type is not stored. This page runs no scripts or actions from the file and submits nothing, but the copy keeps any that the file contains, and another viewer may run them. Changed text fields are redrawn in a plain standard font (multi-line boxes at 11 pt), so they can look different from the original style; characters outside Latin-1 are refused. Fields you do not change are left as they were. Signature fields, buttons and files with an XFA form are not supported. Copies are limited to 20 MB.
